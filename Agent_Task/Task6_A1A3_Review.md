## 4. P1：口径混淆 —— 「解析路径 0 例」≠「语料无样本」

### 4.1 现象

报告 §1 的 Full 分类表列出「**目录内多候选（歧义）= 0**」「**上级目录 = 0**」，
§4 进一步写成「Full 1113 / Primary 963 均无『目录内多候选』」、
「无『上级目录同名 / 唯一候选 / 多候选』」⇒ 读者会理解为
**「语料里根本不存在这类候选」**。

**但语料里存在。** 本对话独立枚举（不走探针）：

| 事实 | 数量 | 明细 |
|---|---:|---|
| **含 ≥2 张图集的目录** | **5 个目录 / 11 张图集** | `h0137s5/umbrella_fly`(2)、`h0243s5/s3`(2)、`h0255s5/skill`(2)、`h0261s5/s3`(3)、`t0269s5/s2`(2) |
| 这些目录里的骨架 | **11 个** | **11/11 全部**被「骨架同名」规则唯一消解 ⇒ **真歧义 = 0** |
| **骨架目录的父目录含 `.atlas.txt`** | **138 个骨架目录**（涉及 **103 个不同的父目录**）/ **145 个单位** | 父目录同名可解 38、**父目录唯一候选 107**、父目录多候选 **0** |
| 骨架目录内 0 张图集 | 0 | — |
| 严格 `basename(dir).atlas.txt` | 0 | 与报告一致 ✔ |

### 4.2 根因：探针分类的**短路顺序**（不是数据问题）

`shared-atlas-layout-probe.mjs:68` 先判「骨架同名命中」并**立即返回**，
⇒ 位于多图集目录里的骨架**永远进不了**「多候选」分支；
`:71` 又只在「目录内 0 张」时才去查上级目录 ⇒ 「上级目录」同理只统计**实际走到的解析路径**。

⇒ 报告的「0 例」是**解析路径计数**，不是**候选存在性计数**。两个口径在结论上恰好一致，
但**表述把"没走到"写成了"不存在"**。

### 4.3 影响评估：**结论与实现方向不变，且被这份数据加强**

- A1 / A2 的**建议都不需要改**：
  - Q6-2 建议「歧义显式拒绝」——真歧义确实 0 例，作为**防御性判据**成立 ✔；
  - Q6-3 建议「**不**实现上级目录回退」——现在有了**更强的理由**：
    若实现回退，**107 个单位**会被父目录的唯一候选「吸走」（语料 0 条实际路径，但风险实在）✔。
- **新增一条必须写进阶段 B 的不变量**：**「骨架同名」必须排在「目录内唯一候选」之前** ——
  否则那 **11 个**位于多图集目录的单位会解析到**错误的图集**（例：`h0261s5/s3` 目录有 3 张图集，
  骨架若改用「唯一候选」就会张冠李戴）。

### 4.4 返修（可直接采用的改写）

**P1-1（必做）** 报告 §1 分类表与 §4 结论改为**双口径**表述：

> **Q6-2**：语料**有** 5 个目录含多张图集（共 11 张）；因「骨架同名优先」全部唯一可解，
> **真歧义 0 例**。⇒ 歧义拒绝仅作**防御性判据**，不得据此宣称支持歧义布局。
>
> **Q6-3**：**无单位实际走上级目录解析路径（0 例）**；但 **138 个骨架目录**的父目录**存在**候选图集（103 个不同父目录）
> （涉及 145 个单位，其中 107 个为「父目录唯一候选」）⇒ **不实现上级目录回退**
> （既无必要，又存在误吸风险）。

§1 分类表相应改为「**解析路径**分类」并加脚注：*分类按实际解析路径统计；
候选存在性见 §4 双口径表*。

**P1-2（必做）** 探针补一个**候选存在性**指标（不改既有分类，避免破坏可复核性）：
每个骨架目录输出 `own / dir / parent` 三个候选数 + 「同名消解」标记，并给分布汇总。
